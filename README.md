# Whilzpro Website

A Next.js portfolio starter for Whilzpro.

## Getting started

Install dependencies and run locally:

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before launch

- Replace the temporary Unsplash images in `app/page.tsx` and `app/globals.css` with Whilzpro's own selected photographs.
- Verify the contact email and Instagram URL.
- Add project detail pages and a real enquiry form when ready.
- Connect the Namecheap domain in Vercel only after deployment is successful. Preserve existing email DNS records.
